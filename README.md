# Humanic plugin

Connect an AI agent to [Humanic](https://humanic.ai), an AI email marketing platform for campaigns, cohorts, and analytics. This plugin bundles two things:

- A hosted MCP server connection: `https://mcp.humanic.ai/mcp` (streamable HTTP, sign in with your Humanic account via OAuth).
- A skill (`skills/humanic/SKILL.md`) that teaches the agent a safe workflow: inspect your organization, choose a cohort, draft a campaign, review it with you, and activate it only a
